# Карточка таксации · 23 октября 2026

Кнопка **«Изменить карточку»** открывает общую форму по структуре оригинальной SOLI-N: лесовладелец и лесничество, категория ГЛФ, квартал и его характеристики, выдел и площадь, макеты 1–5, древостой (10), подрост (31), подлесок (32).

На телефоне поля располагаются в две колонки, строки древостоя — отдельными блоками. Кнопка «Таблица» включает табличный вид с прокруткой внутри блока. На широком экране древостой сразу представлен таблицей. Верхние номера переходят к основным блокам; нижний ряд открывает дополнительные макеты 11–28. Нижний ряд прокручивается на узком экране.

Все разделы используют единый черновик. Переход между макетами сохраняет введённое в нём. **«Сохранить карточку»** применяет поля и строки вместе через существующий механизм сохранения, **«Отмена»** отбрасывает их вместе. Ошибка записи возвращает прежние данные и оставляет черновик открытым. Числа принимаются с запятой; округлённый показ исходного числа не меняет его точность без редактирования.

Полный адрес POS / LESN / KV / KGLF / VD показан без изменения ключей. Год, рельеф и доступность редактируют запись квартала только для категории ГЛФ текущего выдела. Поля макетов 1–5, 31, 32 записываются в исходную строку «Выдел», не в выдуманные дочерние таблицы. Поля без подтверждённых подписей сохранены в раскрываемом блоке с исходными обозначениями.

Показатели макета 5 сохраняются как данные. Автоматические расчёты настольной SOLI-N не перенесены этой правкой. Форматы карт, декодеры CMF2, чтение MDB и фотографии используют прежнюю реализацию.

Изменённый интерфейс включён в офлайн-кэш `solin-field-20261023-5`.
