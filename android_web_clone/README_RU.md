# SOLI-N Field — Android, точная оболочка веб-приложения

Эта версия **не перерисовывает** SOLI-N на Flutter. Исходный \`index.html\`, \`styles.css\`, \`app.js\`, все \`cmf*.js\`, кварталы и справочники копируются из корня **этого же репозитория** в Android APK на этапе сборки.

## Экран и функции
- тот же главный экран «SOLI-N Field», Бугетсайское лесничество, кварталы и выделы;
- таксационные карточки, справочники, создание кварталов/выделов, Transfer;
- та же Leaflet-карта, импорт CMF2 / KML / KMZ / GeoJSON / GPKG / GPX;
- GPS запрашивает реальное разрешение Android;
- экспорт Blob-файлов сохраняется в «Загрузки / SOLI-N»;
- пользовательские локальные изменения хранятся в WebView localStorage.

## Ограничения
- Это точная оболочка **исходной веб-версии GitHub**, а не Flutter-прототипа.
- Основной интерфейс, таксационная база и справочники работают без сервера. Для спутниковых снимков Google и схемы OSM нужен интернет: слои тайлов **не включены** в APK.
- Если в процессе сборки не удалось скачать одну из сторонних библиотек (Leaflet, JSZip, SQL.js, GeoPackage), зависимая функция может потребовать интернет. В журнале сборки выводятся предупреждения.
- Ресурсы карты пользователя, загруженные с телефона, как и в веб-приложении, остаются в памяти открытой страницы; после перезапуска импортируйте файл заново.
- Сборка и тесты Android должны пройти в GitHub Actions. APK с суффиксом debug — тестовый, для Play Store нужна отдельная релизная подпись.
- Содержимое сайта находится в **открытом репозитории**. Не публикуйте в него конфиденциальные производственные данные.

## Где скачать APK
GitHub → Actions → **SOLI-N Field exact web to Android APK** → последний успешный запуск → Artifacts → SOLIN-Field-Exact-Web-APK.

## Собрать локально
Нужны JDK 17, Android SDK (API 35), Gradle 8.10.2 и Python 3:

\`\`\`bash
python3 android_web_clone/prepare_assets.py
gradle -p android_web_clone :app:assembleDebug
\`\`\`

Выход: \`android_web_clone/app/build/outputs/apk/debug/app-debug.apk\`.

## Как обновлять
Внесите правку в исходный веб-проект **в корне репозитория**, затем пересоберите APK. Не редактируйте копию внутри Android assets: она создаётся автоматически. Веб-версия остаётся неизменной на этой ветке.
