# SOLI-N Field — Flutter

Flutter-перенос основной веб-версии SOLI-N Field.

## Принцип разработки
- исходная рабочая версия в корне репозитория остаётся резервной;
- Flutter Web публикуется в `/flutter/`;
- Flutter читает те же `data-meta.json`, `data-manifest.json` и `quarters/q*.json`;
- изменения проверяются на iPhone через Safari так же, как раньше;
- после проверки тот же Flutter-проект используется для Android/iOS сборок.
