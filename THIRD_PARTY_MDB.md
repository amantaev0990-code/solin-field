# Local Access Transfer parser

`vendor/mdb-reader.bundle.js` contains mdb-reader 3.2.0 and its browser dependencies. Upstream: https://github.com/andipaetzold/mdb-reader (MIT). The parser runs in a Web Worker and only reads the selected file. It does not connect to Access, execute SQL, VBA or macros, or write to source MDB/ACCDB files. Data is not uploaded.

The application accepts SOLI-N Transfer MDB/ACCDB, Transfer JSON, and SOLIN-Field-Backup-v2 JSON, with required tables Лесничество, Квартал, Выдел. Limits: 100 MiB input and 500,000 total rows; all user tables are returned, including supporting tables. Password protected, corrupt or unsupported databases return an error. Empty forests are allowed when their Лесничество record exists.

## Verification (2026-10-23)

The exact browser bundle parsed 23 actual Transfer MDB files from the authorized local SOLI-N installation. The files were only read; SHA-256 hashes were unchanged before and after. Their 28 or 29 tables and between 0 and 7,874 stand records were returned. In Chromium/Edge at a 390 × 844 mobile viewport, the actual worker successfully read Комсомольское (115 quarter rows, 611 stands), Бугетсайское (90/471), and Садыкащинское (168/3,706). Transfer JSON, invalid records, missing required tables and backup conversion with GPS were also tested. Zero JavaScript errors or external network requests occurred in that harness. These are browser tests, not physical phone tests. ACCDB is supported by the upstream library; a SOLI-N Transfer ACCDB fixture was not available and has not been declared tested.

## Rebuilding

The bundle is a browser IIFE with bundled Buffer, process, events, streams, crypto and decompression dependencies; it has no Node runtime or CDN dependency. It was built with Rollup, node-resolve (browser:true, preferBuiltins:false), commonjs, JSON, inject (Buffer and process), and terser. `stream` resolves to stream-browserify.

Entry source:

```js
import { Buffer } from "buffer";
import MDBReader from "mdb-reader";
globalThis.SolinMDB = { Reader: MDBReader, Buffer, version: "3.2.0" };
```
