# SOLI-N Field — безопасные обновления через GitHub

## Статус
Разработка в ветке fix/v23-update-center-2026-11-06. Установленная V23 не изменена.
Для первого перехода на сборку с этой кнопкой нужен один ручной APK; затем обновление запускается из раздела «Ещё».
GitHub Releases пока пуст: реального обновления пока нет.

## Защита
1. Проверяются установленный package ID kz.solin.field.v23build, версия и SHA-256 сертификата V23.
2. Кандидаты берутся только из опубликованного latest GitHub Release; тег строго solin-android-v<versionCode>.
3. Единственный APK должен называться SOLIN-Field-update.apk и иметь валидный digest sha256 из GitHub.
4. Загрузка строго по HTTPS из GitHub Releases, ограничена по размеру; SHA-256 и размер перепроверяются в Android.
5. Android читает из APK package ID, подпись и versionCode, запрещает отличающиеся и старые сборки.
6. Только после этого запускается системный установщик Android с подтверждением пользователя.
7. Лесничества, карточки, черновики, MDB и хранилище приложения не изменяются самим модулем обновлений.

## Порядок публикации
1. Проверить ветку и тесты, собрать Android APK с постоянным ключом V23 и возрастающим versionCode.
2. Проверить на реальном планшете импорт/экспорт MDB и локальную сохранность данных.
3. В GitHub Releases создать публичный релиз с точным тегом solin-android-v230002 (или следующим номером) и приложить SOLIN-Field-update.apk.
4. Приложение обнаружит релиз через GitHub API после нажатия «Проверить обновления».

## Важно о приватности
Репозиторий публичный, поэтому APK в GitHub Releases доступен любому. Текущая V23 содержит частные справочники.
НЕЛЬЗЯ публиковать исходный или приватно дополненный APK в открытый Release до проверки прав на данные и отсутствия конфиденциальных материалов.
Закрытый пароль и резервный ключ никогда не публиковать. Однократно установить Actions secret SOLIN_V23_KEYSTORE_PASSWORD.

## Ограничения
Пока нет собранной и испытанной на Android версии с модулем обновлений. Обычная V23 этой кнопки не содержит.
При отсутствии сети, Release, подписи или прав установки обновление отменяется и установленная программа продолжает работать офлайн.
Android может один раз попросить разрешение установки APK из приложения и затем подтвердить само обновление.
Пакет и сертификат должны оставаться неизменными для сохранения данных при установке поверх существующей версии.
