# SOLI-N Field: один раз включить обновления через GitHub

## Что подготовлено
- Рабочая V25 (подписанная прежним сертификатом V23) уже имеет кнопку **«Ещё» → «Проверить обновления»**.
- Проверочный запуск [GitHub Actions 42205860884](https://github.com/amantaev0990-code/solin-field/actions/runs/42205860884): **успешно** собрал V25 из зафиксированного коммита `ca32d438df382466a7b691e9309b3682b3f9cbd3`, выполнил проверки расчётов и справочников; он **не публиковал** выпуск и не получал закрытый ключ.
- Новый workflow [SOLI-N Field — publish V25 for in-app updates](https://github.com/amantaev0990-code/solin-field/actions/workflows/solin-publish-v25.yml) разделяет сборку и подпись. Закрытый ключ и оригинальные справочники разблокируются **только в отдельном job подписи**, после контрольных проверок; workflow не может сгенерировать другой ключ.
- Репозиторий GitHub **публичный**. Стабильный GitHub Release и помещённый в него APK будут доступны любому человеку.

## Обязательное одноразовое действие владельца репозитория (НЕ через чат)
1. Скачать **личную** резервную копию V23 `V23_PRIVATE_SIGNING_BACKUP.zip` из ChatGPT и открыть внутри `signing-private.json`. **Не отправлять пароль в чат, не коммитить JSON или ZIP в GitHub.**
2. Открыть [GitHub Actions Secrets](https://github.com/amantaev0990-code/solin-field/settings/secrets/actions), выбрать **New repository secret**.
3. Name: `SOLIN_V23_KEYSTORE_PASSWORD`; Secret: точное значение поля `password` из `signing-private.json`. Save.
4. Открыть [выпуск V25](https://github.com/amantaev0990-code/solin-field/actions/workflows/solin-publish-v25.yml) → **Run workflow** (branch `main`, `publish=true`). Workflow ещё раз построит приложение, подпишет существующим ключом и опубликует **стабильный** GitHub Release `solin-field-v230005`.
5. Только после зелёного завершения проверить [GitHub Releases](https://github.com/amantaev0990-code/solin-field/releases/latest). Там должен быть **SOLIN-Field-update.apk** с опубликованным GitHub digest SHA-256.
6. На установленной V24: **Ещё → Проверить обновления**. Android покажет подтверждение установки V25; данные сохраняются при совпадении package ID и подписи. Если установлена уже V25, она сообщит «Обновлений нет» — это ожидаемо, поскольку номер версии одинаков.

## Защита и диагностика
- Идентификатор приложения: `kz.solin.field.v23build`.
- Сертификат V23/V24/V25 (SHA-256): `5A1C2E2BF2EFE5AA7382674B651533A11D2B93C802A1C09ADC72656C5A29ED7E`.
- Версия первого релиза V25: `versionCode=230005`.
- Публикация заблокируется, если секрет не установлен, сертификат другой, изменён идентификатор приложения, нарушен SHA-256 оригинальных справочников либо не прошли тесты.
- Нельзя вводить пароль как `workflow_dispatch` input, хранить в репозитории, issue, readme или логах.
- Перед обновлением обязательно сохранить резервный экспорт лесничеств и убедиться в его ненулевом размере. Испытания V25 на планшете и приёмка экспорта MDB в настольном SOLI-N пока не завершены.
- Для будущей V26 нужен новый зафиксированный исходный коммит и `versionCode=230006` (или выше), **ключ остаётся прежним**. Следующий выпуск менять только через проверенный pipeline.
