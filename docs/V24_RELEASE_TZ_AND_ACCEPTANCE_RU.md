# SOLI-N Field V24 — ТЗ и критерии безопасного выпуска

Дата: 06.11.2026. База обновлений: **установленная V23**, не V22.

## Задача
Сделать удобное обновление SOLI-N Field без Google Play и без повторного скачивания из чата. Добавить характеристику типа леса и доступ ко всем нижним макетам в окне древостоя без потери логики расчётов и экспорта.

## 1. Древостой
- В форме «Основные данные · состав древостоя» рядом с составом доступна «Характеристика типа леса (M3TLU)», сохранённая по всему выделу, а не по одной породе Макета 10.
- Список динамически ограничивается исходными справочниками STL/SDP, областью, лесохозяйственной зоной, главной породой и группой типа леса NE2A при её наличии.
- Если справочник отсутствует или неоднозначен, **не заменять** существующий код и не подменять его выдуманным.
- После сохранения состав по породам, возрасту, ярусу, полноте, запасу и группа леса остаются неизменными, за исключением явных правок пользователя и ранее утверждённых корректировок оригинальной логикой.
- Дополнительные макеты: 11, 12, 13, 14, 15, 16, 17, 19, 20, 21, 23, 25, 27, 28, а также быстрый доступ к М31, М32, КТ, печати и контролю рубок. При переходе сначала сохранять состав и тип леса, затем открывать существующий редактор соответствующего макета.

## 2. Обновления
- «Ещё» → «Проверить обновления», запуск только по нажатию, никаких тайных фоновых загрузок.
- Источник: GitHub Releases репозитория amantaev0990-code/solin-field; тег solin-field-v<versionCode>.
- Скачивать только SOLIN-Field-update.apk с валидным digest SHA-256.
- Перед вызовом системного Android установщика проверять: HTTPS и домен, SHA-256 APK, versionCode строго больше установленного, packageId **kz.solin.field.v23build**, SHA-256 сертификата **5A1C2E2BF2EFE5AA7382674B651533A11D2B93C802A1C09ADC72656C5A29ED7E** для установленной и скачанной версии.
- Установка требует системного подтверждения Android и при необходимости разрешения установки из этого источника. Никаких скрытых установок.
- Offline режим, карты, справочники, лесничества, кварталы, выделы, макеты 1–5, 10, 31, 32 и MDB экспорт не менять.

## 3. CI/CD
- Сборка с `SOLIN_GITHUB_UPDATES=1` включает нативный `SolinUpdatePlugin`. В Google Play AAB этот модуль с правом установки APK **не включать**.
- Постоянный PKCS#12 V23 хранится в GitHub в зашифрованном виде. Пароль хранить исключительно в GitHub Actions Secret `SOLIN_V23_KEYSTORE_PASSWORD` и в приватной резервной копии владельца. Никаких новых ключей.
- При сборке восстановить original V23 reference pack (зашифрованная копия в `main/signing`), сверить SHA-256 до сборки и внутри APK.
- Не публиковать автоматически: сначала скачать и проверить кандидат на одном устройстве; GitHub Release публичен, так как репозиторий публичен.

## 4. Обязательная приёмка до публикации
- Установка **поверх V23**, не требует удаления, не меняет каталог данных.
- После обновления те же лесничества, кварталы, выделы, заполненные карточки и фото.
- Работает М5 с несколькими породами, ед. деревьями и свежим сухостоем; проверка ЕШ/К59; М10 по слоям.
- Районы областей выбираются из полной Кл_Рай; типы леса выбираются по связям STL/SDP.
- Экспорт MDB не 0 байт, компьютерный SOLI-N видит карточку без ручного ввода ID выдела.
- Закрытие незавершённого ввода не теряет черновик.
- GitHub без Releases → «Обновлений нет»; поддельный SHA/пакет/сертификат/старая версия → отказ без установки.
- Настоящий полевой тест Android/ПК обязателен. Прохождение unit/Gradle-тестов не заменяет его.
