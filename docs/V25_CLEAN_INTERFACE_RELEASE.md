# SOLI-N Field V25 — полный редизайн интерфейса без переписывания расчётов

Дата: 6 ноября 2026 года. Ветка: `design/v25-clean-interface-2026-11-06`.
Базовое приложение: V24, пакет `kz.solin.field.v23build`, постоянный сертификат V23.

## Результат
- Один интерфейс вместо накопившихся настольных/планшетных/полевых панелей.
- Единая нижняя панель: лесничества, карта, кварталы, справочники, ещё.
- Таксационная карточка: три понятных раздела **Участок / Древостой / Макеты**.
- На планшете макеты располагаются вертикальными карточками без масштабирования старого настольного листа.
- Древостой: породы в читаемом списке, редактирование оригинальных строк по нажатию, табличный режим доступен через кнопку «Таблица».
- Окно редактирования состава: категория угодий, характеристика типа леса, строки пород; дополнительных макетов — один раскрывающийся список (М11–М28, М31, М32, просмотр КТ, печать и контроль).
- Кнопки сохранения и отмены сохраняют исходную семантику; черновики защищены оригинальными функциями V23.
- Редкие действия перенесены в сворачиваемые меню, а разъясняющие абзацы скрыты в секции проверки связей.

## Что принципиально НЕ менялось
Оригинальные справочники, табличные исходники и проверенные модули `solin-apk-mdb.js`, `solin-card-calculations.js`, `solin-readable.js`, `solin-category-rules.js`, значок SOLI-N Field сохранены *побайтово*. Отдельный закрытый `solin-private-refs.packed.bin` встроен идентичным V24. Исходные данные пользователя НЕ очищаются и НЕ мигрируют интерфейсным модулем.

## Ограничения
V25 ещё не проверена физической установкой и экспортом на планшете пользователя или настольным SOLI-N. Перед установкой следует сохранить резервный экспорт. V24 удалять не нужно: сертификат и package ID совпадают, версия увеличена. Новая встроенная кнопка «Проверить обновления» сможет загрузить следующие сборки только после безопасной публикации проверенных GitHub Releases. Публикация GitHub Releases в публичном репозитории не произведена.
