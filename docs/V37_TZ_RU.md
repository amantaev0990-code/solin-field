# SOLI-N Field V37 — техническое задание

Основа: официальный подписанный релиз V36 (versionCode 230016). Новый versionCode — 230017, неизменный packageId и сертификат. APK допускается до 150 МБ.

## Требования

1. **Без старого меню при запуске.** На раннем этапе HTML скрыть старый интерфейс, пока не сформируется новое главное меню. Затем показать только новый экран; при критическом сбое — безопасный запасной вариант, не вечная пустая страница.
2. **Название.** Все пользовательские кнопки и заголовки «Головное меню» заменить на «Главное меню». Нельзя менять исходные Access-справочники и данные лесничеств.
3. **Android Назад.** Аппаратная кнопка или жест возвращают на предыдущий экран приложения, а не закрывают Activity. На корневом экране не выходят из приложения. Открытые модальные окна и редакторы закрываются только крестиком; при несохранённых изменениях работает штатное подтверждение.
4. **Дубли в карточке.** Удалить из видимого блока «Основные данные» вторую пару «Главная порода»/«Характеристика типа леса». Оставить рабочий выбор в макете 3 через исходные SDP/STL/NE2A. Канонические поля модели сохранить для вычислений и сохранения — только визуально скрыть дубль.
5. **Красная «Новая».** Внизу экрана сохранённого выдела широкая красная кнопка «Новая», создающая отдельный НЕ сохранённый выдел того же квартала и КГЛФ с первым следующим номером, большим существующих номеров квартала. Не изменять исходный выдел. Для импортированных кварталов без KGLF в quarterRows использовать категорию открытого выдела. На несохранённой карточке повторную кнопку заблокировать.

## Приёмка

- Нет вспышки старого меню при холодном запуске.
- Название «Главное меню» в пользовательском интерфейсе.
- Android Back возвращает к предыдущему экрану; не закрывает приложение/диалог.
- В редакторе только одна видимая пара выбора М3, выпадающие справочники работают.
- «Новая» создаёт следующий отдельный выдел, сохранение идёт только через штатный редактор; существующие выделы неизменны.
- Сборочные тесты и проверка настоящего подписанного APK подтверждают постоянную подпись, обе офлайн-карты, нормативы, справочники, MDB/Transfer и работоспособность обновления. Полевой тест на планшете — отдельно.

Переписывать расчёты макета 5 и расшифровывать отсутствующие настольные данные в этом релизе не требуется.
