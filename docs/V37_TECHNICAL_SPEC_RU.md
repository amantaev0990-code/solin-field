# Техническое задание — SOLI-N Field V37

**Основание:** пять исправлений по результатам проверки V36 на Android-планшете. **База:** опубликованный подписанный V36 (versionCode 230016), стабильный механизм PackageInstaller. **Целевой выпуск:** V37, versionCode 230017. **Допустимый размер APK:** до 150 МБ (сознательно увеличивать ради размера не требуется).

## 1. Старое главное меню появляется на одну секунду

**Изменение:** при первом запуске не показывать старый черновой экран ни на один кадр. Пока приложение загружает интерфейс/локальную рабочую базу, показывать аккуратный экран запуска SOLI-N Field с фирменной S. Главный экран становится видимым только после перестройки V33/V34 меню. Не переинициализировать приложение и не трогать рабочие записи.

**Приёмка:** на холодном запуске, при медленной загрузке и переключении лесничества старые пункты меню не вспыхивают. В случае ошибки загрузки UI не зависает бесконечно на сплэше.

## 2. Текст «Головное меню»

**Изменение:** заменить надпись «Головное меню» на **«Главное меню»** во всех пользовательских элементах интерфейса и уведомлениях. Не переименовывать программные ключи, таблицы, идентификаторы и маршруты.

**Приёмка:** пользовательские надписи и подписи кнопок не содержат «Головное меню».

## 3. Android «Назад»

**Изменение:** системная кнопка/жест «Назад» осуществляет внутреннюю навигацию (например, карточка → список → главное меню), **не закрывает приложение с одного нажатия**. На главном экране нажатие «Назад» остаётся внутри приложения и показывает короткое уведомление. Если поверх экрана открыто окно, диалог, карточка или форма ввода, «Назад» **не закрывает окно**: закрытие только крестиком, с запросом о несохранённых изменениях. Не менять работающие обновления APK.

**Приёмка:** на планшете с аппаратной кнопкой/жестом не происходит выхода из приложения или потери черновика, после редактирования карточки диалог остаётся открытым.

## 4. Главная порода и тип леса не должны дублироваться

**Изменение:** в редакторе выдела **макет 3** содержит единственные редактируемые поля `M3Pr` (Главная порода) и `M3TLU` (Характеристика типа леса). Из раздела **«Основные данные» / макет 10** обе дублирующие строки удаляются. В DOM должно быть ровно по одному первичному полю; прежний поисковый справочник и строгая проверка SDP/SDP_Tip/STL, группы NE2A, области и лесохозяйственной зоны остаются рабочими. Не создавать второй экземпляр поля в DOM и не менять MDB/Transfer имена.

**Приёмка:** редактировать оба значения можно в макете 3; они корректно сохраняются, зависимые поля пересчитываются, валидируются при выборе и сохранении; в «Основных данных» дублирования нет.

## 5. Красная «Новая» внизу выдела

**Изменение:** на странице открытого выдела внизу под всеми данными разместить **красную кнопку «Новая»**. При нажатии вызывается исходный штатный поток создания нового выдела `openCompForm` в **том же квартале и категории ГЛФ текущего лесничества**. Создаётся незаписанный черновик с новым незанятым номером и пустыми показателями, без копирования состава, запаса, площади или макетов предыдущего выдела. Данные записываются только после штатного «Сохранить». Повторное нажатие на ещё несохранённом черновике не должно уничтожать введённое.

**Приёмка:** после сохранения предыдущий выдел не изменился, новый получил уникальный номер, виден в списке и остаётся после перезапуска. На отмене новый выдел в базе не появляется; активное лесничество/квартал не меняется.

## Неприкосновенные условия

- Оставить `kz.solin.field.v23build`, тот же сертификат SHA-256 `5A1C2E2BF2EFE5AA7382674B651533A11D2B93C802A1C09ADC72656C5A29ED7E`, повышать только `versionCode` до 230017.
- Сохранить проверенную установку по одной кнопке и сетевые повторы V36; не изменять хранилища Android, IndexedDB, экспорт MDB и макеты расчётов.
- Сохранить обе оригинальные офлайн-карты, справочники и фирменный зелёный ярлык.
- Автоматические тесты: отсутствие старого меню на первой отрисовке; название; системная навигация с/без открытого модального окна; ровно один M3Pr/M3TLU в правильном макете; создание нового выдела в том же квартале; подпись и содержимое APK.
- **Релиз только при успешной сборке и проверке.** После публикации нужна проверка на физическом планшете; CI не доказывает правильность Android-жеста на реальном оборудовании.
