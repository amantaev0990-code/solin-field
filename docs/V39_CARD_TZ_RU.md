# ТЗ · Быстрый ввод выдела и КТ

- На экране выдела вместо «Основных данных» и блока «Основные сведения» разместить «Быстрый ввод». Оставить «Изменить карточку» для полного редактора. Убрать «Ещё действия», «Проверить» и старые кнопки панели действий.
- Порядок набивки: номер выдела, категория угодий, главная порода, характеристика типа леса, макеты 10, 31, 32, 23, затем 2 и 4. Остальные доступны через «Все макеты». Для сохранённого выдела номер показывается как идентификатор, для нового он редактируется. Поля используют существующий черновик, справочники и сохранение.
- Enter и экранная кнопка «Ввод ↵» переводят фокус вправо, затем на первую доступную ячейку следующей строки. При завершении макета переходят к следующему макету. Добавление строк остаётся явным. Поля только для чтения пропускаются, Enter в открытом справочнике обрабатывает сам справочник.
- Внизу рядом с красной «Новая» добавить синюю «КТ» того же размера. Она открывает просмотр по настольному образцу «ВыделКрат»: бирюзовая форма, квартал и лесничество, блоки 1–4, таблица состава, блоки 31 и 32, сетка дополнительных макетов и кнопка «Выход». Показывать фактические данные выдела, отсутствующие поля оставлять пустыми.
- Рабочий релиз V38 не менять. Проверить создание и редактирование выдела, навигацию Enter, просмотр КТ и переходы V38 в браузере.
