# План перехода на приватные исходники без поломки обновлений SOLI-N Field

**Ничего не переключать на Private до проверки отдельного канала выпуска APK.**

1. Сохранить полную зеркальную копию репозитория со всеми ветками, коммитами и тегами. Хранить её как зашифрованный архив с отдельным паролем и резервной копией.
2. Находясь в собственном аккаунте GitHub, создать новый **Private** репозиторий для разработки. Это должен быть новый закрытый репозиторий, а НЕ публичный fork. Доступ давать только выбранным разработчикам.
3. Перенести полную историю разработок туда, отдельно проверить, что секретов и служебных данных в истории нет. Публичный репозиторий НЕ считать безопасным местом для исходников.
4. Создать отдельный публичный **release-only** канал: там должны находиться лишь подписанные APK, контрольные суммы и минимальные метаданные. Не выгружать в него source archive и базы MDB.
5. В приватном проекте настроить публикацию в release-only канал через отдельный токен с минимальными правами, сохранённый в GitHub Actions Secrets. Никогда не включать такой токен в APK. Установить фиксированный SHA-256 и проверку подписи.
6. Выпустить переходную APK-версию через **старый работающий публичный канал**. В этой версии приложение должно уметь проверять новый адрес релизов и прежний постоянный сертификат V23. Проверить автообновление на тестовом планшете поверх установленной версии, сохранность карточек и офлайн-работу.
7. Лишь после проверки установки переходной версии и охвата всех необходимых планшетов решать судьбу старого публичного репозитория. Старые сборки могут продолжать обращаться к старому адресу. Закрытие старого репозитория до миграции оборвёт им обновления.
8. Публикация исходников в прошлом не отменяется сменой видимости. Старые клоны, форки, веб-кэши и история коммитов могут оставаться доступными. Удаление/переписывание истории без резервной копии и плана миграции недопустимо.
9. Отдельно документировать права на код, внешние библиотеки, оригинальные нормативные данные и MDB. Шифрование само по себе не устанавливает авторство.

**Текущий статус:** только план. Создание Private репозитория, перенос APK-канала, смена настроек и шифрование полной копии должны быть подтверждены отдельно.
