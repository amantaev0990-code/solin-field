# SOLI-N Field

Мобильное полевое приложение на основе данных и определений SOLI-N.

[Открыть приложение](https://amantaev0990-code.github.io/solin-field/).

Главное окно позволяет выбрать лесничество, создать пустое или загрузить настоящий MDB Transfer и JSON. Базы хранятся раздельно на устройстве и доступны без сети после первой полной загрузки. Карточки и справочники показывают русские названия вместо кодов; служебные данные раскрываются отдельно.

[Изменения, тесты и границы реализации](WORKSPACES_AND_READABILITY.md). Это ещё не полная замена Access: события форм и отчёты воспроизведены не полностью. Мобильный экспорт создаёт ZIP для Windows-конвертера, а не сам MDB; исходные MDB не изменяются.

Контроль: «Ещё → Контроль карточек», кнопка «Контроль» в карточке и проверка квартала. Доступны запросы всех шести исходных групп с подготовкой отдельной копии. После проверки можно просмотреть подготовительные изменения, применить их к лесничеству или отменить применение. Исходные поля и справочники не подменяются предположениями: для полной проверки загрузите полный Transfer; в старых сокращённых данных условия останутся непроверенными. [Проверка против Access и ограничения](NATIVE_CONTROL.md).



## Экспорт для MDB (Windows)

Откройте «Ещё» → **«Экспорт»**. Приложение скачает ZIP-пакет с текущими карточками, таблицами Transfer, инструкцией и PowerShell-конвертером. Этот ZIP **ещё не MDB**: на Windows распакуйте его и выполните `README.txt`. Для создания настоящего `.mdb` нужен исходный Transfer MDB того же лесничества и установленный Microsoft Access / Access Database Engine (DAO). Конвертер создаёт отдельный `Transf_POS_LESN_Год_Field.mdb` и не перезаписывает исходный шаблон.

Формируется копия с данными, которые доступны мобильному приложению; отсутствующие в экспорте вспомогательные таблицы шаблона сохраняются неизменными. Полная совместимость приёма в настольном SOLI-N **ещё не подтверждена** и требует проверки в Access/SOLI-N на резервной копии. Прямое создание MDB на iPhone/Android через браузер пока **не реализовано**; другие кнопки экспорта в меню «Ещё» скрыты, но внутренние данные и функции резервного восстановления не удалены.
## Онлайн-экспорт настоящего MDB (серверная версия)

Во вкладке **«Ещё»** оставлена одна кнопка **«Экспорт»**. При первом использовании пользователь вводит URL своего защищённого MDB-сервера и секретный ключ. Телефон передаёт сохранённые записи по HTTPS, а сервер формирует настоящий Jet MDB на основе `Transf_POS_LESN_GodT.mdb` и возвращает ссылку «Сохранить MDB». Ключ не пишется в GitHub или браузерное постоянное хранилище. При отсутствии настроенного сервера приложение **не выдаёт JSON/ZIP за MDB**. Исходный Transfer на сервере не перезаписывается.

Сервер и инструкции: [mdb-service](mdb-service/README.md). **Сервис ещё не развёрнут**, секрет и оригинальный MDB-шаблон необходимо установить на приватном хосте. До этого экспорт MDB с телефона не работает; код интерфейса и конвертера уже добавлен. Проверка открытия и приёма в настольном SOLI-N ещё обязательна.
