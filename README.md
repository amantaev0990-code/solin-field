# SOLI-N Field

Мобильное полевое приложение на основе данных и определений SOLI-N.

[Открыть приложение](https://amantaev0990-code.github.io/solin-field/).

Главное окно позволяет выбрать лесничество, создать пустое или загрузить настоящий MDB Transfer и JSON. Базы хранятся раздельно на устройстве и доступны без сети после первой полной загрузки. Карточки и справочники показывают русские названия вместо кодов; служебные данные раскрываются отдельно.

[Изменения, тесты и границы реализации](WORKSPACES_AND_READABILITY.md). Это ещё не полная замена Access: все VBA, контроли и отчёты не перенесены. Экспорт — JSON; исходные MDB не изменяются.
