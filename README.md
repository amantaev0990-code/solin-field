# SOLI-N Field

Мобильное полевое приложение для таксации леса на основе настольного SOLI-N.

**[Открыть приложение](https://amantaev0990-code.github.io/solin-field/)**

## Рабочие данные

Лесовладельцы и лесничества хранятся раздельно. Можно импортировать оригинальный Transfer MDB, создать своё лесничество, редактировать кварталы и выделы, работать со справочниками и картами, выполнять контроль карточек. Данные пользователя сохраняются локально в браузере (IndexedDB); изменение рабочего пространства не перезаписывает исходный файл.

Разделы о совместимости, функциях и контроле: [Workspaces](WORKSPACES_AND_READABILITY.md), [контроль SOLI-N](NATIVE_CONTROL.md), [архитектура APK и MDB](APK_AND_MDB_ARCHITECTURE.md).

## Экспорт настоящего MDB на iPhone (экспериментальная версия)

Вкладка **«Ещё» → «Экспорт»** предназначена для выгрузки **готового двоичного Microsoft Access Jet MDB**. Не заменяйте рабочую базу до проверки в настольном SOLI-N.

1. Если оригинальный Transfer MDB импортирован через главный экран после обновления экспортёра, его исходные байты уже сохраняются локально в качестве шаблона.
2. Откройте нужное лесничество и нажмите «Ещё» → «Экспорт».
3. Если исходный MDB ещё не сохранён на этом устройстве, выберите его **один раз** в предложенном окне. Это только настройка формата — рабочие карточки и выделы не заменяются. Приложение проверяет шифры POS, LESN и GodT.
4. Экспортёр создаёт отдельную копию исходного MDB в памяти телефона, записывает актуальные карточки и родственные макеты, повторно читает полученные таблицы и предлагает **«Сохранить MDB»**.
5. Формат имени всегда исходный: `Transf_<POS>_<LESN>_<GodT>.mdb`. POS — шифр лесовладельца/учреждения, LESN — шифр выбранного лесничества, GodT — год. Например, `Transf_213_2_2026.mdb`. Суффиксы `_Field` и `Solin Field` не добавляются.

Исходный MDB не отправляется на удалённый сервер и не изменяется. Подготовка исходного шаблона и обработка данных выполняются локально на iPhone. Для Java-движка используется **CheerpJ 4.3**, загружаемый с внешнего CDN: в первый раз нужен интернет, полностью автономный MDB-экспорт на iPhone пока **не подтверждён**. Использование CheerpJ для организаций требует отдельной проверки условий лицензирования.

**Почему нужен шаблон?** Первоначальное создание нового пустого Jet MDB внутри Safari вызывало `Given rowId is invalid ... Table=MSysObjects`. Теперь применяется локально сохранённый исходный Transfer и его настоящий системный каталог. В Java-чтении разрешён обход индекса `MSysObjects`, если он несовместим с виртуальным файловым каналом. Эта схема ещё должна пройти испытание на самом iPhone.

Java-ядро: `mdb-service/src/main/java/kz/solin/mdb/BrowserMdbWriter.java` и `TransferWriter.java`. Проверки: `mdb-service/src/test/java/kz/solin/mdb/TransferWriterTest.java`. Публикуемый браузерный пакет: `vendor/solin-browser-mdb-v20261028-22.jar`; собирается и тестируется GitHub Actions в `.github/workflows/build-browser-mdb.yml`.

## Android APK и резервный вариант для Windows

Android-реализация использует тот же HTML/JS интерфейс и экспериментальный нативный Jackcess-плагин в `native/android/SolinMdbPlugin.java`. Сборка APK и проверка реальной совместимости экспорта на устройстве ещё необходимы.

Вспомогательный `solin-mdb-bridge.js` позволяет подготовить ZIP с JSON и скриптом `windows/Build-SOLIN-Transfer-MDB.ps1` для конвертации в настоящий MDB на Windows с установленным Access/DAO. **ZIP не является MDB**, а эта функция не заменяет прямую кнопку экспорта на iPhone. Серверный прототип `mdb-service/ExportServer.java` не развёрнут и не нужен браузерной кнопке.

## Что ещё нужно проверить

- Экспорт на настоящем iPhone/Safari, включая повторную выгрузку без выбора шаблона.
- Совпадение всех операционных таблиц, полей, типов, ключей, родственных макетов и значений с оригинальным Transfer. Автоматические Java-тесты проверяют синтетические базы, а не все варианты оригинального SOLI-N.
- Открытие полученного MDB в Microsoft Access и штатный приём в настольном SOLI-N **только на резервной копии**.

До этих испытаний функция остаётся экспериментальной. Не заменяйте настоящие производственные MDB экспортом SOLI-N Field.
