# SOLI-N Field

Мобильное полевое приложение для таксации леса на основе настольного SOLI-N.

**[Открыть приложение](https://amantaev0990-code.github.io/solin-field/)**

## Рабочие данные

Лесовладельцы и лесничества хранятся раздельно. Можно импортировать оригинальный Transfer MDB, создать своё лесничество, редактировать кварталы и выделы, работать со справочниками и картами, выполнять контроль карточек. Данные пользователя сохраняются локально в браузере (IndexedDB); изменение рабочего пространства не перезаписывает исходный файл.

Разделы о совместимости, функциях и контроле: [Workspaces](WORKSPACES_AND_READABILITY.md), [контроль SOLI-N](NATIVE_CONTROL.md), [архитектура APK и MDB](APK_AND_MDB_ARCHITECTURE.md).

## Экспорт настоящего MDB на iPhone (экспериментальная версия)

**«Ещё» → «Экспорт» → сохранить готовый `.mdb`. Никаких окон «Выбрать файл» и загрузки исходного MDB.** Приложение автоматически скачивает проверенный пустой Access Jet MDB, сформированный в GitHub Actions из структуры 18 известных таблиц SOLI-N Field. Шаблон содержит **ноль записей**, без пользовательских данных, и заполняется текущими карточками на телефоне. Проверяются двоичный формат, таблицы, число строк и значения. Название файла — оригинальное `Transf_<POS>_<LESN>_<GodT>.mdb` (например, `Transf_213_2_2026.mdb`) без приписки Field.

Исходная база SOLI-N при выгрузке не используется и не изменяется; пользователь не загружает никакой файл. Но **типы столбцов встроенной схемы определены по данным приложения**, а не по официальному оригинальному Transfer (в нём было 29 операционных таблиц, в редакторе представлены 18). Файл будет настоящим Jet MDB, но гарантировать приём настольным SOLI-N пока нельзя. Проверяйте только на тестовой копии.

Исходный код Java движка: `mdb-service/src/main/java/kz/solin/mdb/TransferWriter.java`. Генерация пустого MDB: `BlankTransferTemplate.java` и `scripts/prepare-blank-mdb.mjs`. Автоматическая публикация: `.github/workflows/build-browser-mdb.yml`. Публичный шаблон: `vendor/solin-empty-transfer-v20261028-23.mdb`. CI проверяет отсутствие строк, сохранение 18 таблиц и создание/повторное чтение MDB из 1243 тестовых записей; запуск в Safari и штатный приём настольным SOLI-N ещё предстоит проверить.

Java-движок CheerpJ 4.3 загружается с внешнего CDN, поэтому полностью автономный экспорт на iPhone не гарантирован. Для организационного использования CheerpJ надо отдельно проверить условия лицензирования.

## Android APK и резервный вариант для Windows

Android-реализация использует тот же HTML/JS интерфейс и экспериментальный нативный Jackcess-плагин в `native/android/SolinMdbPlugin.java`. Сборка APK и проверка реальной совместимости экспорта на устройстве ещё необходимы.

Вспомогательный `solin-mdb-bridge.js` позволяет подготовить ZIP с JSON и скриптом `windows/Build-SOLIN-Transfer-MDB.ps1` для конвертации в настоящий MDB на Windows с установленным Access/DAO. **ZIP не является MDB**, а эта функция не заменяет прямую кнопку экспорта на iPhone. Серверный прототип `mdb-service/ExportServer.java` не развёрнут и не нужен браузерной кнопке.

## Что ещё нужно проверить

- Экспорт на настоящем iPhone/Safari, включая повторную выгрузку без выбора шаблона.
- Совпадение всех операционных таблиц, полей, типов, ключей, родственных макетов и значений с оригинальным Transfer. Автоматические Java-тесты проверяют синтетические базы, а не все варианты оригинального SOLI-N.
- Открытие полученного MDB в Microsoft Access и штатный приём в настольном SOLI-N **только на резервной копии**.

До этих испытаний функция остаётся экспериментальной. Не заменяйте настоящие производственные MDB экспортом SOLI-N Field.
