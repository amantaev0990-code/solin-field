# SOLI-N Field

Мобильное полевое приложение на основе данных и определений SOLI-N.

[Открыть приложение](https://amantaev0990-code.github.io/solin-field/).

Главное окно позволяет выбрать лесничество, создать пустое или загрузить настоящий MDB Transfer и JSON. Базы хранятся раздельно на устройстве и доступны без сети после первой полной загрузки. Карточки и справочники показывают русские названия вместо кодов; служебные данные раскрываются отдельно.

[Изменения, тесты и границы реализации](WORKSPACES_AND_READABILITY.md). Это ещё не полная замена Access: события форм и отчёты воспроизведены не полностью. Экспорт — JSON; исходные MDB не изменяются.

Контроль: «Ещё → Контроль карточек», кнопка «Контроль» в карточке и проверка квартала. Доступны запросы всех шести исходных групп с подготовкой отдельной копии. После проверки можно просмотреть подготовительные изменения, применить их к лесничеству или отменить применение. Исходные поля и справочники не подменяются предположениями: для полной проверки загрузите полный Transfer; в старых сокращённых данных условия останутся непроверенными. [Проверка против Access и ограничения](NATIVE_CONTROL.md).



## Экспорт для MDB (Windows)

Откройте «Ещё» → **«Экспорт для MDB (Windows)»**. Приложение скачает ZIP-пакет с текущими карточками, таблицами Transfer, инструкцией и PowerShell-конвертером. Этот ZIP **ещё не MDB**: на Windows распакуйте его и выполните `README.txt`. Для создания настоящего `.mdb` нужен исходный Transfer MDB того же лесничества и установленный Microsoft Access / Access Database Engine (DAO). Конвертер создаёт отдельный `Transf_POS_LESN_Год_Field.mdb` и не перезаписывает исходный шаблон.

Формируется копия с данными, которые доступны мобильному приложению; отсутствующие в экспорте вспомогательные таблицы шаблона сохраняются неизменными. Полная совместимость приёма в настольном SOLI-N **ещё не подтверждена** и требует проверки в Access/SOLI-N на резервной копии. Прямое создание MDB на iPhone/Android через браузер пока **не реализовано**; прежний «Экспорт Transfer» по-прежнему выдаёт JSON для обзора.
